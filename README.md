# Daryn AI frontend

Адаптивный модуль управления классами Daryn AI на HTML, CSS и чистом JavaScript. Фреймворков, сборщика и внешних зависимостей нет.

## Страницы

- `index.html` — перенаправление на единственный рабочий модуль классов.
- `classes.html` — список классов со статистикой, фильтрами и карточками.
- `class-create.html` — создание класса с пустыми реквизитами и видимым списком добавленных учеников.
- `class-edit.html` — редактирование класса с заполненными данными и полным списком из 24 учеников.
- `app.js` — добавление, поиск, редактирование и удаление учеников; создание, фильтрация и удаление классов; хранение данных в `localStorage`.
- `docs/references/` — 15 исходных скриншотов UI-kit и отдельных продуктовых экранов. UI-kit хранится только как визуальный референс и не является страницей продукта.
- `docs/DESIGN_NOTES.md` — результаты исследования Figma, правила адаптивности, UX и доступности.

## Запуск

Проект можно открыть напрямую через `index.html`. Для корректной проверки переходов удобнее запустить локальный сервер:

```powershell
python -m http.server 4173
```

Затем открыть `http://localhost:4173/`.

## Технические принципы

- единый набор CSS custom properties для цветов, размеров, радиусов и теней;
- mobile-first поведение на ключевых порогах `640px`, `900px` и `1100px`;
- минимальная высота интерактивной области `44px`;
- семантические `nav`, `main`, `section`, `article`, `form`, `details`;
- видимые `:focus-visible`, skip-link и поддержка `prefers-reduced-motion`;
- доступные HTML-формы и диалоги подтверждения;
- сохранение пользовательских изменений в `localStorage` браузера.
